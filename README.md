E-Commerce Sales Dashboard

Project Overview

This project is an interactive E-Commerce Sales Dashboard developed using Microsoft Power BI to analyze and visualize e-commerce sales performance.

The dashboard provides a clear view of sales trends, product performance, customer behavior, profitability, and other important business metrics. It helps transform raw sales data into meaningful insights for better business decision-making.


Tools & Technologies

- Microsoft Power BI
- Power Query – Data cleaning and transformation
- DAX – Calculated measures and KPIs
- Excel / CSV – Dataset
- Data Visualization – Interactive charts, graphs, cards, and slicers

Data Preparation

The dataset was processed using Power Query before building the dashboard.

The data preparation process included:

- Removing unnecessary data
- Handling missing values
- Correcting data types
- Cleaning and transforming columns
- Creating relationships between tables where required
- Preparing the data for analysis


Data Analysis

The dashboard was developed using DAX measures and calculated columns to generate meaningful business metrics and enable dynamic analysis.

Users can interact with the dashboard using filters and slicers to analyze the data from different perspectives.
